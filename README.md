# terry-surveys — Research Survey Book Workspace

[한국어](#한국어) | **English**

> Unified workspace for creating, building, and managing bilingual (KO/EN) research survey books deployed on Cloudflare Pages.

Part of the [terryum-ai](https://github.com/terryum/terryum-ai) ecosystem. See the [main README](https://github.com/terryum/terryum-ai#readme) for the broader site architecture.

---

## What This Workspace Does

Each survey is a **multi-chapter bilingual research book** built from Markdown. All three current surveys share:

- A **canonical directory structure** (generated by `shared/scaffold.py`)
- A **shared build pipeline** (`shared/build_site.py`) producing dark-mode glassmorphism static sites
- A **single BibTeX master** (`bibtex/references.bib`) — surveys maintain local subsets
- A **single Glossary master** (`glossary/master_{ko,en}.md`) — surveys maintain local subsets
- A **standard agent pipeline**: `deep-researcher → critical-analyst → book-writer → image-curator → fact-checker → qa-reviewer`

Root [`CLAUDE.md`](CLAUDE.md) is the authoritative document for these standards. Edit it whenever the standard evolves.

## Key Commands

| Command | What It Does |
|---|---|
| `python3 build.py <name>` | Build a single survey |
| `python3 build.py --all` | Build all surveys |
| `python3 build.py --new <name>` | Scaffold a new survey (canonical layout) |
| `python3 build.py --list` | List available surveys |
| `python3 build.py --index` | Rebuild the BibTeX `refs_index.json` |

## Creating a New Survey

```bash
# 1. Scaffold (creates CLAUDE.md, README, LICENSE, .github/ISSUE_TEMPLATE/, scripts/push.sh,
#    book/{ko,en}/ch01.md + glossary.md, etc.)
python3 build.py --new my-new-survey

# 2. Edit surveys/my-new-survey/survey.json with your chapter structure
# 3. Fill in scripts/push.sh REPO_URL with your standalone GitHub repo
# 4. Write chapters (and grep bibtex/ + glossary/ masters before adding new entries)
# 5. Build
python3 build.py my-new-survey

# 6. Deploy (sync to external repo → Cloudflare Pages auto-redeploys)
cd surveys/my-new-survey && bash scripts/push.sh "initial build"

# 7. Register in homepage gallery
/survey https://my-new-survey.pages.dev
```

## Shared Masters: Why

- **BibTeX master** prevents duplicate keys across surveys and lets refs be shared (e.g., `pi02024flow` is the same entry everywhere it appears).
- **Glossary master** keeps terminology consistent — "VLA", "Cross-embodiment gap", "Diffusion Policy" all carry the same canonical definition across books.
- Workflow for both: grep master first → reuse if found → add to master first, then survey if new.

See [`bibtex/README.md`](bibtex/README.md) and [`glossary/README.md`](glossary/README.md).

## Group-Restricted Surveys

Surveys can restrict content to specific groups (e.g., SNU collaborators):

- Content directories (`book/`, `assets/`, `docs/`, `scripts/`) are listed in the root `.gitignore`
- The survey's existence and metadata (`survey.json`, `README.md`, `LICENSE`, `CONTRIBUTING.md`) stay public
- Private content is deployed by syncing to a private external repo; Cloudflare Pages serves it to authenticated viewers only

# terry-surveys — 연구 서베이 북 워크스페이스

**한국어** | [English](#terry-surveys--research-survey-book-workspace)

> Cloudflare Pages에 배포되는 한/영 이중언어 연구 서베이 북을 통합 관리하는 워크스페이스.

[terryum-ai](https://github.com/terryum/terryum-ai) 생태계의 일부입니다.

## 워크스페이스가 하는 일

각 서베이는 **다챕터 한/영 연구서**로, 세 서베이가 공통으로 공유하는 것:

- `shared/scaffold.py`가 생성하는 **정규 디렉토리 구조**
- `shared/build_site.py`로 dark-mode + glassmorphism 정적 사이트를 만드는 **공유 빌드 파이프라인**
- `bibtex/references.bib` **단일 BibTeX 마스터** (서베이는 subset 유지)
- `glossary/master_{ko,en}.md` **단일 Glossary 마스터** (서베이는 subset 유지)
- `deep-researcher → critical-analyst → book-writer → image-curator → fact-checker → qa-reviewer` 표준 에이전트 파이프라인

표준의 원본은 루트 [`CLAUDE.md`](CLAUDE.md).

## 주요 명령어

| 명령어 | 기능 |
|---|---|
| `python3 build.py <이름>` | 단일 서베이 빌드 |
| `python3 build.py --all` | 전체 서베이 빌드 |
| `python3 build.py --new <이름>` | 새 서베이 스캐폴드 |
| `python3 build.py --list` | 서베이 목록 |
| `python3 build.py --index` | BibTeX `refs_index.json` 재생성 |

## 공유 마스터의 의의

- **BibTeX 마스터**: 키 중복 방지, 같은 논문은 어느 서베이든 동일 키 사용
- **Glossary 마스터**: 같은 용어는 어느 책에서 봐도 동일 정의

두 마스터 모두 "grep 먼저 → 있으면 재사용 → 없으면 마스터 먼저 추가 → 서베이로 복사" 규칙을 따른다.

## 그룹 제한 서베이

일부 서베이는 그룹 회원에게만 공개된다 (예: SNU 협업). 콘텐츠(`book/`, `assets/`, `docs/`, `scripts/`)는 루트 `.gitignore`에 등록되어 공개 repo에 푸시되지 않고, 별도 private 외부 repo를 통해 Cloudflare Pages가 인증된 독자에게만 서빙한다. 메타데이터(`survey.json`, `README.md`, `LICENSE`, `CONTRIBUTING.md`)는 공개된다.
